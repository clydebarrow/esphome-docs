The `counter` sensor holds a whole number that can be set and changed by [actions](/automations/actions/), and
reports it as a sensor. The value is kept as a signed 64-bit integer and, by default, is stored on the device so
that it survives a restart.

```yaml
# Example configuration entry
sensor:
  - platform: counter
    name: "Door Openings"
    id: door_openings
```

The counter starts at zero. Change it with the [`counter.increment`](#counterincrement-action) and
[`counter.set_value`](#counterset_value-action) actions.

> [!NOTE]
> The sensor state is published as a floating point number, so it shows whole numbers exactly only up to
> 16,777,216. Larger values are still counted and stored exactly, but the published value is rounded.

## Configuration Variables

- **restore** (*Optional*, boolean): Whether to store the value on the device and restore it after a restart.
  Defaults to `true`. See [Flash Wear](/components/preferences/#flash-wear) for how often the value is written to flash.
- **sensor** (*Optional*, [ID](/guides/configuration-types#id)): The ID of a [sensor](/components/sensor/). The counter
  increases by one each time this sensor publishes a value. The value the sensor publishes is not used.
- All other options from [Sensor](/components/sensor/).

To count events from other kinds of component, call the [`counter.increment`](#counterincrement-action) action from
that component's automations instead. For example, to count presses of a binary sensor:

```yaml
binary_sensor:
  - platform: gpio
    pin: GPIOXX
    name: "Door"
    on_press:
      - counter.increment: door_openings
```

## `counter.increment` Action

This [Action](/automations/actions#all-actions) adds a number to the counter. The number defaults to `1`
and can be negative to count down.

```yaml
on_...:
  # Add one
  - counter.increment: my_counter

  # Add a chosen amount
  - counter.increment:
      id: my_counter
      value: -5
```

Configuration options:

- **id** (**Required**, [ID](/guides/configuration-types#id)): The ID of the counter. May be left out when only
  one counter is configured.
- **value** (*Optional*, integer, [templatable](/automations/templates)): The amount to add. Defaults to `1`. Must be
  within the range of a signed 64-bit integer. If the result goes past the largest or smallest 64-bit value, it wraps
  around.

## `counter.set_value` Action

This [Action](/automations/actions#all-actions) sets the counter to a given value.

```yaml
on_...:
  - counter.set_value:
      id: my_counter
      value: 100
```

Configuration options:

- **id** (**Required**, [ID](/guides/configuration-types#id)): The ID of the counter. May be left out when only
  one counter is configured.
- **value** (**Required**, integer, [templatable](/automations/templates)): The value to set. Must be within the range
  of a signed 64-bit integer.

When only one counter is configured, the value can be given directly:

```yaml
on_...:
  - counter.set_value: 0
```
